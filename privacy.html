Kebijakan Privasi

Talent Operating System (TOS)

1. Ringkasan

Kami menghargai privasi Anda. Dokumen ini menjelaskan data apa yang kami kumpulkan, bagaimana kami menggunakannya, dan hak-hak Anda terkait data tersebut.

2. Data yang Dikumpulkan

Jenis Data Contoh Tujuan
Input Form Tujuan karier, status, gaya kerja, catatan personal Menghasilkan analisis AI yang personal
Hasil Analisis Skor archetype, roadmap, summary Disimpan di browser Anda (localStorage)
Progress Mingguan Checkbox minggu 1-14 Tracking progres di browser Anda
Data Teknis Alamat IP, user agent Keamanan, rate limiting, pencegahan abuse

3. Bagaimana Data Diproses

  • Input form Anda dikirim ke Google Gemini AI melalui server kami untuk menghasilkan analisis.
  • Hasil analisis disimpan di browser Anda (localStorage). Kami tidak menyimpan hasil di server kami.
  • Data teknis (IP address) digunakan hanya untuk rate limiting dan keamanan, tidak untuk identifikasi personal.

4. Pihak Ketiga

Data input Anda diproses melalui:

  • Google Gemini AI — untuk menghasilkan analisis. Tunduk pada Kebijakan Privasi Google.
  • Vercel — hosting dan serverless functions. Tunduk pada Kebijakan Privasi Vercel.

5. Penyimpanan Data

  • Data hasil analisis disimpan hanya di browser Anda (localStorage).
  • Kami tidak memiliki database yang menyimpan data personal Anda.
  • Data di browser dapat Anda hapus kapan saja melalui tombol "Mulai Ulang" atau membersihkan cache browser.

6. Hak Anda

Anda berhak untuk:

  • Mengakses — Semua data tersimpan di browser Anda dan bisa diakses kapan saja.
  • Menghapus — Gunakan tombol "Mulai Ulang" atau bersihkan cache browser.
  • Menolak — Anda bisa berhenti menggunakan layanan kapan saja.
  • Portabilitas — Anda bisa mengunduh hasil analisis dalam format PDF.

7. Keamanan

Kami menerapkan langkah-langkah keamanan berikut:

  • API key tersimpan aman di server (environment variables), tidak terekspos ke browser.
  • Rate limiting untuk mencegah penyalahgunaan.
  • CORS validation untuk memastikan hanya domain resmi yang bisa mengakses API.
  • HTTPS untuk enkripsi data dalam transit.

8. Cookie

Kami tidak menggunakan cookies. Data disimpan menggunakan localStorage browser yang hanya bisa diakses oleh domain kami.

9. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Tanggal pembaruan terakhir tercantum di bagian bawah halaman ini.
